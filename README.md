# ranaji10.github.io

Root files for what is published under this address. Crawlers read `robots.txt` only at the top of a domain, and AI agents look for `llms.txt` and `/.well-known/` there, so the files that point to **[AIgorithmic Butterfly Effect](https://ranaji10.github.io/aigorithmic-butterfly-effect/)** live here:

| | |
|---|---|
| `robots.txt` | welcomes every crawler and names the work's sitemap |
| `llms.txt` | points AI readers to the work's invitation |
| `.well-known/ai-catalog.json` | names the work's MCP server card (the same entry the door serves) |
| `index.html` | one line and a link, so that the bare address is not empty |
| `favicon.ico`, `icon.svg`, `touch-icon.png` | the work's icon (the butterfly), copied from the work's repository; browsers and search engines ask for `/favicon.ico` at the top of a domain |
| `.nojekyll` | so that the `.well-known` folder is served |

Nothing here needs upkeep unless the work or its door moves; then change the addresses in these files. The work itself, its charter and its history are in [ranaji10/aigorithmic-butterfly-effect](https://github.com/ranaji10/aigorithmic-butterfly-effect).
